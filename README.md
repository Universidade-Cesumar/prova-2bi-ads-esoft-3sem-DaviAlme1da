## 📌 Sobre o Projeto

O sistema foi desenvolvido para resolver o problema de controle de estoque de materiais utilizados em aulas práticas, substituindo o gerenciamento manual realizado em planilhas.

O sistema permite:

* cadastrar novos materiais
* visualizar todos os materiais cadastrados
* pesquisar materiais por nome
* realizar baixa de estoque
* excluir materiais
* visualizar o total de materiais cadastrados
* identificar itens com estoque crítico (menor que 10 unidades)

## 🛠️ Funcionalidades Implementadas

### Cadastro de Materiais

Permite registrar novos materiais informando:

* nome
* quantidade

### Controle de Estoque

Permite:

* dar baixa em materiais
* impedir baixas inválidas
* atualizar o estoque automaticamente

### Pesquisa de Materiais

Permite localizar materiais pelo nome em tempo real.

### Dashboard

Exibe:

* total de materiais cadastrados

### Estoque Crítico

Materiais com quantidade inferior a 10 unidades recebem destaque visual para facilitar o monitoramento.
